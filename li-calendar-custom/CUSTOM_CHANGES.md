# Custom ACTIA/Personal Build Notes

This source tree is based on `CrankZ/li-calendar` v1.0.0.

Custom changes included here:
- Week number column on the left of each calendar row.
- Setting to show/hide week numbers.
- Setting for the week containing January 1 to start at W0 or W1.
- Runtime Windows/WebView2 scaling compensation so the taskbar popup is not clipped on high-DPI displays.

The original upstream license and source files are retained in this directory.
